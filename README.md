# F50 Monitor

专为中兴 (ZTE) F50 5G 随身 WiFi 打造的轻量 macOS 菜单栏监控工具。

<p align="center">
  <img src="assets/preview.png" width="360" alt="F50 Monitor Preview">
</p>

## 功能特点

- ⚡ **菜单栏监控**：网速、信号、CPU/内存占用、温度及设备数
- 📶 **信号评级**：实时获取 5G/4G 制式、RSRP / RSRQ / SINR 指标
- 🚀 **签约速率**：解析 QCI 及 QoS 签约上下行速率
- ⚙️ **快捷控制**：一键直达 Web 后台、自定义刷新频率与显示模式

## 下载使用

从 [Releases](https://github.com/kelvinsze/f50-monitor/releases) 下载 `F50.Monitor.zip` 解压运行。

```bash
# 本地编译
./build.sh
```
