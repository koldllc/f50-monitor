# F50 Monitor 隐私政策 (Privacy Policy)

**生效日期**：2026 年 8 月 22 日
**开发者**：Kold (`koldllc`)
**适用平台**：iOS / iPadOS

欢迎使用 **F50 Monitor**（以下简称“本应用”）。本隐私政策旨在清晰透明地向您说明本应用如何处理您的数据与隐私。我们承诺严格遵循最小必要原则，绝不收集、滥用或出售您的个人隐私数据。

---

## 1. 核心数据处理原则与本地网络访问

- **本地网关直连**：本应用作为随身 WiFi（中兴 F50 5G MiFi 等设备）的状态监控与管理工具，所有核心功能（信号强度、蜂窝频段、速率、流量统计、短信读取与发送）均在您的 iPhone / iPad 与设备本地网关（默认 `192.168.0.1`，或用户自定义局域网/穿透地址）之间通过原生 Socket 及 HTTP/HTTPS 进行点对点直连通信。
- **无远程中转服务器**：日常监控数据不会经过任何第三方或开发者中转服务器，所有设备指标与短信内容仅在您的手机本地解析与呈现。
- **本地凭据安全**：您在设置中填写的后台登录口令均安全保存在 iOS 系统的 **安全钥匙串 (Keychain)** 中，不会明文存储，更不会上传至公网。

---

## 2. 用户主动反馈与诊断数据收集

当您在使用过程中遇到设备适配问题或网络异常，并**主动在“设置 → 问题反馈与设备适配”中提交反馈**时，应用会通过安全加密通道（HTTPS）向我们的反馈接收接口发送以下信息：

1. **设备与诊断信息**：设备型号、系统版本、应用版本，以及信号、频段、流量、连接状态和脱敏后的近期运行日志，用于兼容性分析；
2. **脱敏后的网关接口响应快照**：用于分析随身 WiFi 固件接口字段差异。提交前，网关响应中的密码、Token、IMEI、SIM 卡 ICCID/IMSI、手机号和短信正文会在本地过滤或掩码处理；
3. **用户填写的问题描述与联系方式**（选填，用于开发者跟进适配进展）；
4. **用户选取的附加截图**（选填，经 PhotosUI 系统相册选择器由用户主动授权单张上传）。截图按用户选择的内容上传，应用会提示不要包含密码、短信正文或其他敏感信息。

> 💡 **提示**：若您不主动发起反馈与诊断，应用不会产生任何上述网络上传行为。

## 3. 权限使用说明

| 权限名称 | 系统标识 | 使用目的 |
| :--- | :--- | :--- |
| **本地网络 (Local Network)** | `NSLocalNetworkUsageDescription` | 用于发现并连接局域网内的 F50 随身 WiFi 网关（`192.168.0.1`）以及原生 ADB 端口（5555），以读取设备硬件与信号状态。 |
| **后台应用刷新** | `BGAppRefreshTask` | 配合 iOS 系统智能调度机制，在后台适时唤醒以刷新桌面小组件（WidgetKit）数据缓存与新短信未读提醒。 |
| **相册读取 (选填)** | `PhotosUI` (系统照片选择器) | 仅在用户主动发起反馈时，允许用户选取单张问题排查截图进行上传。 |
| **本地通知** | `UNUserNotificationCenter` | 当随身 WiFi 接收到新短信时，在手机本地弹出未读通知（仅本地生成，不使用远程 APNs 推送）。 |

## 4. 演示模式 (Demo Mode)

本应用内置“演示模式 (Demo Mode)”。在未连接物理随身 WiFi 设备时，用户可开启演示模式浏览所有 5G 信号仪表盘、流量追踪、短信交互与反馈界面。演示模式下的反馈提交仅在本地模拟，不产生任何真实网络请求。

---

## 5. 第三方 SDK 与数据共享

本应用**未集成**任何第三方广告 SDK、用户行为统计 SDK 或追踪框架（Tracking Frameworks）。我们不会跨应用追踪用户，亦不会向任何第三方数据经纪商出售用户数据。
